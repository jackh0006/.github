# jackh0006 community health files

This repository provides default community health files for repositories owned by **jackh0006**. GitHub applies these files when a repository does not provide its own.

## Contents

- `SECURITY.md` — coordinated vulnerability disclosure
- `CONTRIBUTING.md` — contribution workflow and expectations
- `CODE_OF_CONDUCT.md` — Contributor Covenant 2.1
- `SUPPORT.md` — support boundaries and safe reporting
- `.github/ISSUE_TEMPLATE/` — bug and feature request templates
- `.github/PULL_REQUEST_TEMPLATE.md` — review checklist

Individual repositories may override any file with a project-specific version.
